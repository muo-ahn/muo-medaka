# Spec — 브리딩 용어 전수 목록과 용어 간 매핑

## 목표
개량 메다카 업계(일본 중심, 한국·영어권 포함)의 브리딩 용어를 가능한 한 전부 모아 나열하고,
서로 다른 용어 사이의 관계(동의어·포함·조합·충돌·기존 ontology 대응)를 매핑한다.

## 범위
- 형질 용어(체색, 광택/체외광, 비늘, 지느러미, 체형, 눈, 무늬), 품종명, 등급·수식어(強光, 極 등),
  브리딩 은어(固定率, 表現 등) 수집. 용어마다 출처 URL.
- 일본어 / 읽기(romaji) / 한국어 / 영어 표기 대응.
- 용어 간 관계 매핑과 기존 seed의 OrnamentalTrait 45개와의 대응.
- 산출물: `docs/research/breeder-vocabulary-2026-09.md` (+ `.csv`).

## 비범위
- seed YAML(`data/seed/`) 수정, vocabulary.py 변경, 새 predicate/ADR.
- 유전자·논문 매핑.
- 유료 자료 구매(JMA 품종분류 매뉴얼 등). 접근 가능 여부만 기록.

## 수용 기준
- AC-1: 모든 용어 행에 최소 1개의 출처 URL과 접근일이 있다. 출처 없는 표기는 unverified로 표시된다.
- AC-2: 각 용어가 kind(단위 형질 / 품종명 / 등급·수식어 / 은어) 와 axis 로 분류되어 있다.
- AC-3: 용어 간 관계가 닫힌 관계 집합(same_as, variant_spelling, broader/narrower, composed_of, collides_with, seed_match)으로 표기되고, 관계마다 근거(출처 또는 추론 표시)가 있다.
- AC-4: 기존 seed OrnamentalTrait 45개 각각에 대해 대응 용어가 있거나 "업계 용어 없음(lab only)"으로 표시된다.
- AC-5: 이름 충돌(같은 단어·다른 형질, 예: longfin vs ロングフィン) 후보가 별도 표로 모인다.
- AC-6: 무작위 20개 행의 출처를 별도 검증 패스가 확인하고, 불일치율을 문서에 기록한다.
- AC-7: 수집 종료 기준과 포화 관찰(마지막 출처들이 새 용어를 얼마나 더했는지)이 문서에 적힌다.

## 열린 결정
- 업계 정의 출처의 권위 순위(협회 매뉴얼 > 도감 > 번식장 > 블로그)는 잠정. 사용자 확인 필요.
- 품종명 층을 ontology에 넣을지는 이 결과를 보고 정한다.
